只要 `Key_S0553/` 和 `docs/` 两个文件夹。

## 总览：写 4 个函数，3 步

| 步骤 | 做什么 | 放在主控工程的哪里 |
|---|---|---|
| **①** | 写 4 个平台函数（另有 2 个写成空函数即可） | 新建 `hal_s0553.c`，加进编译 |

## ① 写 4 个函数（新建 `hal_s0553.c`）

按 `Key_S0553/S0553_HAL.h` 的声明实现。签名与职责如下，**实现由你按平台填写**：

```c
/* 就这 4 个 —— 组件唯一的对外设依赖 */
uint8_t  S0553_HAL_UartInit(void);           /* TODO：开时钟/引脚/中断，就绪返回 S0553_HAL_OK(0) */
uint16_t S0553_HAL_UartRxAvailable(void);    /* TODO：返回接收缓冲里可读的字节数 */
uint8_t  S0553_HAL_UartReadByte(void);       /* TODO：取 1 字节（仅当上面 >0 时被调用） */
void     S0553_HAL_UartWriteByte(uint8_t b); /* TODO：发 1 字节，保证字节顺序 */
```


串口接收建议用**中断 + 环形缓冲**（组件最大帧 261 字节，缓冲建议 ≥300，索引 ≥16bit）。

> ⚠️ 这个缓冲是**你的数据**：ISR 写、主循环读，属于跨上下文共享，
> 请用"单生产者单消费者"写法（ISR 只改写索引、主循环只改读索引，无需关中断）。
>
> 临界区为什么裸机能留空、以及上面这个缓冲为何组件保护不到，见
> [`S0553_Porting_Advanced.md` → 裸机与临界区](S0553_Porting_Advanced.md#裸机与临界区)。

## ② 启动（`main()` 里，硬件就绪后）—— 一行，不阻塞

```c
S0553_Init();     /* 协议栈 + 显示模块 + 打开串口；立即返回 */
```

**连接不用你管**：上电后第一次 `S0553_Task()` 就会自动发起连接；连不上每 2s 重试，直到成功；掉线后下一次调用立即重连。所以**不需要**调 `S0553_Connect()`（组件里也已没有阻塞版的 `S0553_Startup()`）。

> 需要"连不上就报错停机"时，自己在主循环里用 `S0553_IsConnected()` + 一个计数变量做超时判断即可，
> 不必让组件阻塞等待

## ③ 主循环（**严格 10ms** 调一次）

```c
static uint16_t s_Tick = 0;

void Task_10ms(void)
{
    S0553_Task();                    /* ★必须：通信 + UI + 自动连接/重连 + 周期刷新 */

    if (++s_Tick >= 50)              /* 50 × 10ms = 500ms，周期按产品需要调 */
    {
        s_Tick = 0;
        Host_PushAllDataPoints();    /* 推全部数据点（含工作状态 POWER） */
    }
}
```

**开机不用你管**：推送里的 `S0553_DP_POWER` 非 0 时组件自动开机（LOGO → 2s → 主页），
推 0 时自动黑屏关机。主控**不需要**调 `S0553Display_PowerOn()` / `PowerOff()`。

> 节拍必须准：组件内部所有计时（2s 探活、2s 看门狗、2s 连接重试、10s 周期刷新）都按这个 10ms 计数。

## 推数据：7 行

```c
void Host_PushAllDataPoints(void)
{
    S0553_Host_NotifyValue(S0553_DP_TIME_MIN, <按摩剩余时间-分>);
    S0553_Host_NotifyValue(S0553_DP_TIME_SEC, <按摩剩余时间-秒>);
    S0553_Host_NotifyValue(S0553_DP_PROGRAM,  <程序序号：0=手动，1..N=自动>);
    S0553_Host_NotifyValue(S0553_DP_WISE,     <手法序号：仅手动模式有效>);
    S0553_Host_NotifyValue(S0553_DP_LANGUAGE, <语言：0=CN 1=EN 2=DE 3=FR>);
    S0553_Host_NotifyValue(S0553_DP_ZERO_GRAVITY, <零重力挡位：0=关闭，1/2/3=三档>);
    /* ★工作状态放【最后】推：组件收到非 0 会立即开机显示页面，
       此时其余数据点已在镜像里，首屏就能显示正确内容 */
    S0553_Host_NotifyValue(S0553_DP_POWER,    <工作状态：0=关机，非0=开机>);
}
```

**值没变组件什么都不做**，不重绘也不发帧，所以放心每次全推。

## 数据点（就这 7 个）

| 数据点 | 含义 |
|---|---|
| `S0553_DP_TIME_MIN` | 按摩剩余时间-分 |
| `S0553_DP_TIME_SEC` | 按摩剩余时间-秒 |
| `S0553_DP_PROGRAM` | 当前程序：`0`=手动，`1..N`=自动程序 |
| `S0553_DP_WISE` | 手法序号（仅 `PROGRAM==0` 手动时有效） |
| `S0553_DP_LANGUAGE` | 语言：`0`=CN `1`=EN `2`=DE `3`=FR |
| `S0553_DP_ZERO_GRAVITY` | 零重力挡位：`0`=关闭，`1`/`2`/`3`=三档（`S0553ZeroGravityLevel`） |
| `S0553_DP_POWER` | **工作状态 / 开关机**：`0`=关机（黑屏），**非 0 = 开机**。由主控把自身工作状态映射后推送，组件自动开关机 |

取值范围由**主控**持有并钳制，组件不关心。

## 可选：让屏上的旋钮 / 按键能改数值

不写也能正常显示（列表页的旋转、短按都是组件自治）。只有"用户要在屏上直接调数值"时才加：

```c
/* 定义【强符号】函数即覆盖组件侧的弱符号默认实现，无需再调 Register */
void S0553Host_OnCommand(S0553HostCommand cmd, S0553DataPoint dp, int16_t arg)
{
    /* 裁决 + 钳制 → 只更新【自己的状态】；不用回推 */
    /* 结果由下一次"定时推送"带回组件（最迟一个推送周期） */
}
```

## 自检（6 条）

- [ ] 启动只调了 `S0553_Init()`，**没**自己调 `S0553_Connect()`（连接由组件自动完成）
- [ ] 主循环严格 10ms 调 `S0553_Task()`
- [ ] 推送里包含 `S0553_DP_POWER`（否则停在关机黑屏态；主控**不必**调 `PowerOn()`）
- [ ] 开机推了一次全量数据点，之后按周期推
- [ ] 屏上能看到程序名和时间 `mm:ss`
- [ ] 旋转、短按在列表页上生效
